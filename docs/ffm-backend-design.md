# FFM Native Backend — Code Design Document

## Overview

This document specifies the concrete class structure, module layout, and data flow for an FFM-based native backend that calls `libglide_ffi` directly from Scala, bypassing the Java Glide client entirely.

The design preserves the existing public API (`ValkeyCommands[F, K, V]`, `Valkey[IO].utf8(uri)`) while replacing the implementation layer underneath.

---

## Module Structure

```
modules/
├── core/                          # Shared types, algebras, codecs (UNCHANGED)
│   └── src/main/scala/.../
│       ├── algebra/               # Command traits (StringCommands, KeyCommands, etc.)
│       ├── codec/Codec.scala      # Encoding/decoding (decoupled from GlideString)
│       ├── connection/            # ADT types (ValkeyConnection, etc.)
│       ├── model/                 # Config, errors, response types
│       └── effect/                # Log, MkValkey (becomes backend-polymorphic)

├── effects/                       # Java Glide backend (current implementation)
│   └── src/main/scala/.../
│       ├── BaseValkey.scala       # ValkeyCommands impl via Java Glide JNI
│       ├── Valkey.scala           # Entry point constructors
│       └── ValkeyCommands.scala   # Composite trait
│
├── native/                        # NEW: FFM backend
│   └── src/main/scala/.../
│       ├── ffi/                   # Raw FFM bindings to libglide_ffi
│       │   ├── GlideFfi.scala     # MethodHandle definitions (generated or hand-written)
│       │   ├── NativeArena.scala  # Arena lifecycle as Resource[F, *]

│       │   └── ResponseParser.scala # MemorySegment -> Scala type decoding

│       └── Valkey.scala           # Entry point (same API as effects module)
│
└── log4cats/                      # Unchanged
```

## Theory of Operation

### Current Flow (Java Glide)

```
IO.flatMap(valkey.get("key"))
  → Codec.encode("key") → GlideString
  → baseClient.get(glideString) → CompletableFuture[GlideString]
  → Async[F].fromCompletableFuture(...)
  → Option(result).map(Codec.decode) → F[ValkeyResponse[Option[String]]]
```

Under the hood, the Java client:
1. Builds a protobuf `CommandRequest(callback_idx, GET, ["key"])`
2. Serializes to `byte[]`
3. Calls `GlideNativeBridge.executeCommandAsync(handle, bytes, callbackId)` via JNI
4. Rust deserializes protobuf, executes command
5. Rust callback worker calls JNI `successCallback` → completes `CompletableFuture`

### New Flow (FFM Direct)

```
IO.flatMap(valkey.get("key"))
  → Codec.encode("key") → Array[Byte]
  → CallbackRegistry.register() → (callbackId, Deferred[F, ResponseSegment])
  → GlideFfi.command(handle, GET, argsSegment, callbackId)  [FFM downcall]
  → Deferred.get → MemorySegment
  → ResponseParser.decodeOptionalString(segment) → F[ValkeyResponse[Option[String]]]
```

Under the hood:
1. Encode key to `Array[Byte]`, write into Arena-managed `MemorySegment`
2. Register a `Deferred[F, *]` keyed by callback ID
3. Single FFM downcall: `glide_command(handle, cmd_type, args_ptr, arg_lens, arg_count, callback_id)`
4. Rust executes command, calls our upcall stub with `(callback_id, response_ptr)`
5. Upcall stub looks up the `Deferred`, completes it with the response pointer
6. Fiber resumes, decodes `MemorySegment` to Scala types

**What's eliminated**: Protobuf construction, protobuf serialization, JNI byte[] copy, protobuf deserialization, CompletableFuture allocation, GlideString wrapping.

## Class Definitions

### `ffi/GlideFfi.scala` — Raw Native Bindings

```scala
package dev.profunktor.valkey4cats.native.ffi

import java.lang.foreign.*
import java.lang.invoke.MethodHandle

/** Low-level FFM bindings to libglide_ffi.
  *
  * These map 1:1 to the extern "C" functions exported by the Rust FFI crate.
  * Generated by jextract from the cbindgen-produced lib.h, or hand-written.
  */
private[native] object GlideFfi:

  private val lib: SymbolLookup = SymbolLookup.libraryLookup("libglide_ffi", Arena.global())
  private val linker: Linker = Linker.nativeLinker()

  // ─── Client Lifecycle ───

  /** create_client(config_bytes: *const u8, config_len: usize, 
    *   success_cb: fn_ptr, failure_cb: fn_ptr) -> *mut c_void */
  val createClient: MethodHandle = linker.downcallHandle(
    lib.find("create_client").orElseThrow(),
    FunctionDescriptor.of(
      ValueLayout.ADDRESS,      // returns: client handle pointer
      ValueLayout.ADDRESS,      // config_bytes: *const u8
      ValueLayout.JAVA_LONG,    // config_len: usize
      ValueLayout.ADDRESS,      // success_callback: fn ptr
      ValueLayout.ADDRESS       // failure_callback: fn ptr
    )
  )

  /** close_client(client: *mut c_void) */
  val closeClient: MethodHandle = linker.downcallHandle(
    lib.find("close_client").orElseThrow(),
    FunctionDescriptor.ofVoid(ValueLayout.ADDRESS)
  )

  // ─── Command Execution ───

  /** command(client: *mut c_void, request_type: u32,
    *   args: *const *const u8, arg_lens: *const usize, arg_count: usize,
    *   callback_id: u64) */
  val command: MethodHandle = linker.downcallHandle(
    lib.find("command").orElseThrow(),
    FunctionDescriptor.ofVoid(
      ValueLayout.ADDRESS,      // client handle
      ValueLayout.JAVA_INT,     // request_type (command enum)
      ValueLayout.ADDRESS,      // args: *const *const u8
      ValueLayout.ADDRESS,      // arg_lens: *const usize
      ValueLayout.JAVA_LONG,    // arg_count: usize
      ValueLayout.JAVA_LONG     // callback_id: u64
    )
  )

  /** batch(client: *mut c_void, request_bytes: *const u8, request_len: usize,
    *   callback_id: u64) */
  val batch: MethodHandle = linker.downcallHandle(
    lib.find("batch").orElseThrow(),
    FunctionDescriptor.ofVoid(
      ValueLayout.ADDRESS,
      ValueLayout.ADDRESS,
      ValueLayout.JAVA_LONG,
      ValueLayout.JAVA_LONG
    )
  )

  // ─── Memory Management ───

  /** free_command_response(ptr: *mut c_void) */
  val freeCommandResponse: MethodHandle = linker.downcallHandle(
    lib.find("free_command_response").orElseThrow(),
    FunctionDescriptor.ofVoid(ValueLayout.ADDRESS)
  )

  /** free_response_arena(ptr: *mut c_void) */
  val freeResponseArena: MethodHandle = linker.downcallHandle(
    lib.find("free_response_arena").orElseThrow(),
    FunctionDescriptor.ofVoid(ValueLayout.ADDRESS)
  )

  // ─── Upcall Descriptors (for registering callbacks) ───

  /** success_callback(callback_id: u64, response_ptr: *mut c_void) */
  val successCallbackDescriptor: FunctionDescriptor = FunctionDescriptor.ofVoid(
    ValueLayout.JAVA_LONG,    // callback_id
    ValueLayout.ADDRESS       // response pointer
  )

  /** failure_callback(callback_id: u64, error_ptr: *const u8, error_len: usize, error_type: u32) */
  val failureCallbackDescriptor: FunctionDescriptor = FunctionDescriptor.ofVoid(
    ValueLayout.JAVA_LONG,    // callback_id
    ValueLayout.ADDRESS,      // error message pointer
    ValueLayout.JAVA_LONG,    // error message length
    ValueLayout.JAVA_INT      // error type enum
  )
```

### `ffi/NativeArena.scala` — Arena Lifecycle

```scala
package dev.profunktor.valkey4cats.native.ffi

import cats.effect.{IO, Resource}
import java.lang.foreign.{Arena, MemorySegment, ValueLayout}

/** Arena management tied to Cats Effect Resource lifecycle.
  *
  * Provides helpers for allocating command arguments as native memory.
  */
private[native] object NativeArena:

  /** A shared arena whose lifetime is managed by Resource.
    * Shared (not confined) because CE fibers may resume on different threads. */
  def shared: Resource[IO, Arena] =
    Resource.fromAutoCloseable(IO(Arena.ofShared()))

  /** Allocate a byte array as a native MemorySegment within the given arena. */
  def allocBytes(arena: Arena, bytes: Array[Byte]): MemorySegment =
    val seg = arena.allocate(bytes.length.toLong)
    MemorySegment.copy(bytes, 0, seg, ValueLayout.JAVA_BYTE, 0, bytes.length)
    seg

  /** Allocate an array of pointers (for args: *const *const u8). */
  def allocPointerArray(arena: Arena, segments: Array[MemorySegment]): MemorySegment =
    val arr = arena.allocate(ValueLayout.ADDRESS, segments.length.toLong)
    segments.zipWithIndex.foreach { (seg, i) =>
      arr.setAtIndex(ValueLayout.ADDRESS, i.toLong, seg)
    }
    arr

  /** Allocate an array of lengths (for arg_lens: *const usize). */
  def allocLengthArray(arena: Arena, lengths: Array[Long]): MemorySegment =
    val arr = arena.allocate(ValueLayout.JAVA_LONG, lengths.length.toLong)
    lengths.zipWithIndex.foreach { (len, i) =>
      arr.setAtIndex(ValueLayout.JAVA_LONG, i.toLong, len)
    }
    arr
```

### `CallbackRegistry.scala` — Async Response Dispatch

```scala
package dev.profunktor.valkey4cats.native

import cats.effect.{IO, Deferred, Ref}
import cats.effect.std.Dispatcher
import java.lang.foreign.{Arena, Linker, MemorySegment, ValueLayout}
import java.lang.invoke.{MethodHandle, MethodHandles, MethodType}
import java.util.concurrent.ConcurrentHashMap
import java.util.concurrent.atomic.AtomicLong

/** Manages the mapping between callback IDs and pending IO fibers.
  *
  * When the Rust async runtime completes a command, it invokes our upcall stub
  * with the callback ID. We look up the corresponding Deferred and complete it.
  *
  * This is the critical bridge between Rust's async model and Cats Effect's fiber model.
  */
private[native] final class CallbackRegistry private (
    dispatcher: Dispatcher[IO],
    arena: Arena
):
  import CallbackRegistry.*

  private val nextId = new AtomicLong(0L)
  private val pending = new ConcurrentHashMap[Long, Deferred[IO, Either[NativeError, MemorySegment]]]()

  /** Register a new pending command. Returns (callbackId, deferred). */
  def register: IO[(Long, Deferred[IO, Either[NativeError, MemorySegment]])] =
    for
      d  <- Deferred[IO, Either[NativeError, MemorySegment]]
      id  = nextId.getAndIncrement()
      _   = pending.put(id, d)
    yield (id, d)

  /** Called from the native upcall on success. Runs on a Rust worker thread. */
  private def onSuccess(callbackId: Long, responsePtr: MemorySegment): Unit =
    val d = pending.remove(callbackId)
    if d != null then
      dispatcher.unsafeRunAndForget(d.complete(Right(responsePtr)))

  /** Called from the native upcall on failure. Runs on a Rust worker thread. */
  private def onFailure(callbackId: Long, errorPtr: MemorySegment, errorLen: Long, errorType: Int): Unit =
    val d = pending.remove(callbackId)
    if d != null then
      val msgBytes = errorPtr.asSlice(0, errorLen).toArray(ValueLayout.JAVA_BYTE)
      val msg = new String(msgBytes, java.nio.charset.StandardCharsets.UTF_8)
      val err = NativeError(errorType, msg)
      dispatcher.unsafeRunAndForget(d.complete(Left(err)))

  /** The FFM upcall stub for success — a native function pointer backed by onSuccess. */
  val successStub: MemorySegment =
    val mh = MethodHandles.lookup().bind(this, "onSuccess",
      MethodType.methodType(classOf[Unit], classOf[Long], classOf[MemorySegment]))
    Linker.nativeLinker().upcallStub(mh, ffi.GlideFfi.successCallbackDescriptor, arena)

  /** The FFM upcall stub for failure — a native function pointer backed by onFailure. */
  val failureStub: MemorySegment =
    val mh = MethodHandles.lookup().bind(this, "onFailure",
      MethodType.methodType(classOf[Unit], classOf[Long], classOf[MemorySegment], classOf[Long], classOf[Int]))
    Linker.nativeLinker().upcallStub(mh, ffi.GlideFfi.failureCallbackDescriptor, arena)

object CallbackRegistry:
  import cats.effect.Resource

  final case class NativeError(errorType: Int, message: String)

  def make(dispatcher: Dispatcher[IO], arena: Arena): CallbackRegistry =
    new CallbackRegistry(dispatcher, arena)

  /** Resource that creates a Dispatcher + Arena + Registry together. */
  def resource: Resource[IO, CallbackRegistry] =
    for
      dispatcher <- Dispatcher.sequential[IO]
      arena      <- Resource.fromAutoCloseable(IO(Arena.ofShared()))
      registry    = make(dispatcher, arena)
    yield registry
```

### `NativeClient.scala` — Client Lifecycle

```scala
package dev.profunktor.valkey4cats.native

import cats.effect.{IO, Resource}
import dev.profunktor.valkey4cats.model.{ValkeyClientConfig, ValkeyClusterConfig}
import dev.profunktor.valkey4cats.native.ffi.{GlideFfi, NativeArena}
import java.lang.foreign.{Arena, MemorySegment}

/** Represents a live connection to Valkey via the native FFI layer.
  *
  * Wraps the opaque client handle pointer returned by create_client.
  * Closing this resource calls close_client on the native side.
  */
private[native] final class NativeClient private (
    val handle: MemorySegment,
    val registry: CallbackRegistry
)

private[native] object NativeClient:

  /** Create a standalone client from config. 
    *
    * Serializes connection config as protobuf (the only place protobuf is used),
    * passes to create_client with our callback stubs.
    */
  def standalone(config: ValkeyClientConfig): Resource[IO, NativeClient] =
    for
      registry <- CallbackRegistry.resource
      arena    <- Resource.fromAutoCloseable(IO(Arena.ofShared()))
      client   <- Resource.make(connect(config, registry, arena))(release)
    yield client

  /** Create a cluster client from config. */
  def cluster(config: ValkeyClusterConfig): Resource[IO, NativeClient] =
    for
      registry <- CallbackRegistry.resource
      arena    <- Resource.fromAutoCloseable(IO(Arena.ofShared()))
      client   <- Resource.make(connectCluster(config, registry, arena))(release)
    yield client

  private def connect(
      config: ValkeyClientConfig,
      registry: CallbackRegistry,
      arena: Arena
  ): IO[NativeClient] = IO {
    val configBytes = ConfigSerializer.serializeStandalone(config)
    val configSeg = NativeArena.allocBytes(arena, configBytes)
    val handle = GlideFfi.createClient.invokeExact(
      configSeg,
      configBytes.length.toLong,
      registry.successStub,
      registry.failureStub
    ).asInstanceOf[MemorySegment]
    new NativeClient(handle, registry)
  }

  private def connectCluster(
      config: ValkeyClusterConfig,
      registry: CallbackRegistry,
      arena: Arena
  ): IO[NativeClient] = IO {
    val configBytes = ConfigSerializer.serializeCluster(config)
    val configSeg = NativeArena.allocBytes(arena, configBytes)
    val handle = GlideFfi.createClient.invokeExact(
      configSeg,
      configBytes.length.toLong,
      registry.successStub,
      registry.failureStub
    ).asInstanceOf[MemorySegment]
    new NativeClient(handle, registry)
  }

  private def release(client: NativeClient): IO[Unit] = IO {
    GlideFfi.closeClient.invokeExact(client.handle)
  }
```

### `NativeValkey.scala` — Command Implementation

```scala
package dev.profunktor.valkey4cats.native

import cats.effect.{Async, IO}
import dev.profunktor.valkey4cats.ValkeyCommands
import dev.profunktor.valkey4cats.codec.Codec
import dev.profunktor.valkey4cats.effect.Log
import dev.profunktor.valkey4cats.model.{ValkeyError, ValkeyResponse}
import dev.profunktor.valkey4cats.native.ffi.{CommandType, GlideFfi, NativeArena}
import java.lang.foreign.{Arena, MemorySegment}

/** ValkeyCommands implementation backed by direct FFM calls to libglide_ffi.
  *
  * Each command:
  *   1. Encodes args via Codec to byte arrays
  *   2. Allocates a short-lived Arena for the command's native memory
  *   3. Registers a callback and gets a Deferred
  *   4. Makes a single FFM downcall
  *   5. Awaits the Deferred (fiber suspends, no thread blocked)
  *   6. Decodes the response MemorySegment
  *   7. Frees the response via free_command_response
  */
private[native] final class NativeValkey[F[_]: Async, K, V](
    client: NativeClient,
    keyCodec: Codec[K],
    valueCodec: Codec[V]
)(using log: Log[F])
    extends ValkeyCommands[F, K, V]:

  private val F = Async[F]

  /** Execute a command and decode the response. */
  private def exec[A](cmdType: Int, args: Array[Array[Byte]])(
      decode: MemorySegment => A
  ): F[ValkeyResponse[A]] =
    F.flatMap(F.delay {
      // Register callback
      client.registry.register
    }) { case (callbackId, deferred) =>
      F.flatMap(F.delay {
        // Allocate args in a per-command arena (short-lived)
        val arena = Arena.ofConfined()
        val argSegments = args.map(NativeArena.allocBytes(arena, _))
        val argsPtr = NativeArena.allocPointerArray(arena, argSegments)
        val argsLens = NativeArena.allocLengthArray(arena, args.map(_.length.toLong))

        // FFM downcall — non-blocking, returns immediately
        GlideFfi.command.invokeExact(
          client.handle,
          cmdType,
          argsPtr,
          argsLens,
          args.length.toLong,
          callbackId
        )
        arena.close() // args are copied by Rust, safe to free
      }) { _ =>
        // Await async response from Rust
        F.flatMap(deferred.get) {
          case Right(responsePtr) =>
            F.map(F.delay {
              val result = decode(responsePtr)
              GlideFfi.freeCommandResponse.invokeExact(responsePtr)
              result
            })(ValkeyResponse.ok)

          case Left(err) =>
            F.pure(ValkeyResponse.err(
              ValkeyError.fromMessage(err.message)
            ))
        }
      }
    }

  /** Encode a key to bytes. */
  private def encodeKey(key: K): Array[Byte] = keyCodec.encodeBytes(key)

  /** Encode a value to bytes. */
  private def encodeValue(value: V): Array[Byte] = valueCodec.encodeBytes(value)

  // ─── String Commands ───

  override def get(key: K): F[ValkeyResponse[Option[V]]] =
    exec(CommandType.Get, Array(encodeKey(key))) { response =>
      ResponseParser.decodeOptional(response, valueCodec)
    }

  override def set(key: K, value: V): F[ValkeyResponse[Unit]] =
    exec(CommandType.Set, Array(encodeKey(key), encodeValue(value))) { _ => () }

  override def mGet(keys: Set[K]): F[ValkeyResponse[Map[K, V]]] =
    val keyList = keys.toList
    val args = keyList.map(encodeKey).toArray
    exec(CommandType.MGet, args) { response =>
      ResponseParser.decodeMap(response, keyList, keyCodec, valueCodec)
    }

  override def incr(key: K): F[ValkeyResponse[Long]] =
    exec(CommandType.Incr, Array(encodeKey(key)))(ResponseParser.decodeLong)

  // ─── Key Commands ───

  override def del(keys: K*): F[ValkeyResponse[Long]] =
    exec(CommandType.Del, keys.map(encodeKey).toArray)(ResponseParser.decodeLong)

  override def exists(key: K): F[ValkeyResponse[Boolean]] =
    exec(CommandType.Exists, Array(encodeKey(key)))(ResponseParser.decodeBoolean)

  override def expire(key: K, seconds: Long): F[ValkeyResponse[Boolean]] =
    exec(CommandType.Expire, Array(encodeKey(key), seconds.toString.getBytes))(
      ResponseParser.decodeBoolean
    )

  override def ttl(key: K): F[ValkeyResponse[Long]] =
    exec(CommandType.TTL, Array(encodeKey(key)))(ResponseParser.decodeLong)

  // ... (all other commands follow the same pattern)
```

### `ffi/ResponseParser.scala` — Decoding Native Responses

```scala
package dev.profunktor.valkey4cats.native.ffi

import dev.profunktor.valkey4cats.codec.Codec
import java.lang.foreign.{MemorySegment, ValueLayout}
import java.nio.charset.StandardCharsets

/** Decodes response MemorySegments returned by Rust into Scala types.
  *
  * The response format follows the RESP3 value encoding used by glide-core:
  *   - Null pointer → None
  *   - Bulk string → pointer + length
  *   - Integer → i64
  *   - Array → count + element pointers
  *   - Map → count + key/value pairs
  */
private[native] object ResponseParser:

  def decodeLong(seg: MemorySegment): Long =
    seg.get(ValueLayout.JAVA_LONG, 0)

  def decodeBoolean(seg: MemorySegment): Boolean =
    decodeLong(seg) != 0L

  def decodeString(seg: MemorySegment): String =
    val len = seg.get(ValueLayout.JAVA_LONG, 0)
    val dataPtr = seg.get(ValueLayout.ADDRESS, 8).reinterpret(len)
    new String(dataPtr.toArray(ValueLayout.JAVA_BYTE), StandardCharsets.UTF_8)

  def decodeBytes(seg: MemorySegment): Array[Byte] =
    val len = seg.get(ValueLayout.JAVA_LONG, 0)
    val dataPtr = seg.get(ValueLayout.ADDRESS, 8).reinterpret(len)
    dataPtr.toArray(ValueLayout.JAVA_BYTE)

  def decodeOptional[V](seg: MemorySegment, codec: Codec[V]): Option[V] =
    if seg == MemorySegment.NULL || seg.address() == 0L then None
    else Some(codec.decodeBytes(decodeBytes(seg)))

  def decodeList[V](seg: MemorySegment, codec: Codec[V]): List[V] =
    val count = seg.get(ValueLayout.JAVA_LONG, 0).toInt
    val elementsPtr = seg.get(ValueLayout.ADDRESS, 8).reinterpret(count.toLong * 16)
    (0 until count).map { i =>
      val elemSeg = elementsPtr.asSlice(i.toLong * 16, 16)
      codec.decodeBytes(decodeBytes(elemSeg))
    }.toList

  def decodeMap[K, V](
      seg: MemorySegment,
      keys: List[K],
      keyCodec: Codec[K],
      valueCodec: Codec[V]
  ): Map[K, V] =
    val values = decodeList(seg, valueCodec)
    keys.zip(values).collect { case (k, v) => k -> v }.toMap
```

### Modified `Codec.scala` — Backend-Agnostic

```scala
package dev.profunktor.valkey4cats.codec

/** Type class for encoding/decoding values.
  *
  * Backend-agnostic: works with both GlideString (Java backend)
  * and raw byte arrays (FFM native backend).
  */
trait Codec[A]:
  /** Encode to raw bytes (used by native backend). */
  def encodeBytes(value: A): Array[Byte]

  /** Decode from raw bytes (used by native backend). */
  def decodeBytes(bytes: Array[Byte]): A

  /** Encode to GlideString (used by Java backend). 
    * Default implementation wraps encodeBytes. */
  def encode(value: A): glide.api.models.GlideString =
    glide.api.models.GlideString.of(encodeBytes(value))

  /** Decode from GlideString (used by Java backend). 
    * Default implementation unwraps to bytes. */
  def decode(gs: glide.api.models.GlideString): A =
    decodeBytes(gs.getBytes())
```

This keeps the `core` module backend-independent. The `encode`/`decode` methods with GlideString become pass-through adapters only compiled when the Java Glide dependency is on the classpath.

```scala
/** Entry point for the native FFM backend.
  *
  * Same user-facing API as the Java-backed Valkey object:
  * {{{
  *   import dev.profunktor.valkey4cats.native.Valkey
  *
  *   Valkey[IO].utf8("valkey://localhost:6379").use { cmd =>
  *     cmd.set("key", "value") >> cmd.get("key")
  *   }
  * }}}
  */
object Valkey:

  class ValkeyPartiallyApplied[F[_]: Async: Log]:

    def utf8(uri: String): Resource[F, ValkeyCommands[F, String, String]] =
      val config = ValkeyClientConfig.fromUri(uri)
      for
        client <- NativeClient.standalone(config)
      yield new NativeValkey[F, String, String](
        client, Codec.utf8Codec, Codec.utf8Codec
      )

    def simple[K, V](uri: String)(using kCodec: Codec[K], vCodec: Codec[V]): Resource[F, ValkeyCommands[F, K, V]] =
      val config = ValkeyClientConfig.fromUri(uri)
      for
        client <- NativeClient.standalone(config)
      yield new NativeValkey[F, K, V](client, kCodec, vCodec)

    def fromConfig[K, V](config: ValkeyClientConfig)(using kCodec: Codec[K], vCodec: Codec[V]): Resource[F, ValkeyCommands[F, K, V]] =
      for
        client <- NativeClient.standalone(config)
      yield new NativeValkey[F, K, V](client, kCodec, vCodec)

    def clusterUtf8(seedUris: String*): Resource[F, ValkeyCommands[F, String, String]] =
      val config = ValkeyClusterConfig.fromUris(seedUris)
      for
        client <- NativeClient.cluster(config)
      yield new NativeValkey[F, String, String](
        client, Codec.utf8Codec, Codec.utf8Codec
      )

  def apply[F[_]: Async: Log]: ValkeyPartiallyApplied[F] =
    new ValkeyPartiallyApplied[F]
```

## Data Flow: `valkey.get("mykey")` — Side by Side

### Java Backend (current)

| Step | What happens | Allocation |
|------|-------------|-----------|
| 1 | `Codec.utf8Codec.encode("mykey")` | `GlideString` (heap) |
| 2 | `CommandRequest.newBuilder().setType(GET).addArgs(gs)` | Protobuf builder (heap) |
| 3 | `.build().toByteArray()` | `byte[]` (heap) |
| 4 | JNI `executeCommandAsync(handle, bytes, id)` | JNI local refs |
| 5 | Rust: copy bytes from JNI, parse protobuf | Rust Vec (native) |
| 6 | Rust: execute GET, get response | — |
| 7 | JNI callback: `resp_value_to_java()` → `GlideString` | Java object (heap) |
| 8 | `CompletableFuture.complete(glideString)` | — |
| 9 | `Async[F].fromCompletableFuture(...)` | `IO` thunk |
| 10 | `Option(gs).map(valueCodec.decode)` | `String` (heap) |

**Heap allocations**: ~6 per command (GlideString, protobuf builder, byte[], response GlideString, CompletableFuture, decoded String)

### FFM Backend (proposed)

| Step | What happens | Allocation |
|------|-------------|-----------|
| 1 | `Codec.utf8Codec.encodeBytes("mykey")` | `byte[]` (heap, reusable) |
| 2 | `Arena.allocate` + copy bytes to native | MemorySegment (off-heap, arena-scoped) |
| 3 | `CallbackRegistry.register` | `Deferred` (heap) |
| 4 | FFM downcall `command(handle, GET, argsPtr, lens, 1, id)` | — (registers only) |
| 5 | `arena.close()` — args freed | — |
| 6 | Rust: reads args directly (zero-copy), executes GET | — |
| 7 | Rust: calls success upcall `(id, response_ptr)` | — |
| 8 | `Deferred.complete(Right(ptr))` | — |
| 9 | `ResponseParser.decodeOptional(ptr, codec)` | `String` (heap) |
| 10 | `GlideFfi.freeCommandResponse(ptr)` | — |

**Heap allocations**: ~3 per command (byte[] for key, Deferred, decoded String)

## Open Questions

1. **Arena per command vs shared arena** — Current design uses a per-command confined arena for args (closed immediately after downcall since Rust copies). Alternative: batch multiple commands into a shared arena, amortizing allocation cost. Benchmark needed.

2. **Response memory ownership** — Does Rust allocate the response on a bump allocator that we must explicitly free? Or does it use a response arena pattern (free all at once)? Need to study the Go client's `free_command_response` / `free_response_arena` usage.

3. **Pub/Sub callback lifetime** — Pub/Sub requires long-lived callback registration. The upcall stub arena must outlive the subscription. This maps naturally to `Resource` but needs careful design for the subscribe/unsubscribe lifecycle.

4. **Batch/Pipeline optimization** — The `batch` FFI function takes a serialized batch. Should we build a typed batch DSL that encodes commands into the batch format? Or pipeline individual `command` calls (which Rust already pipelines internally)?

5. **GraalVM Native Image compatibility** — FFM works in GraalVM but requires metadata configuration. Worth investigating for serverless/container use cases.
